# Mes Recettes 🍽️

Site de recettes de cuisine développé avec React et Vite.

## Fonctionnalités

- Recherche de recettes via l'API DummyJSON
- Affichage de la fiche détail d'une recette
- Ajout et suppression de favoris (persistés en localStorage)
- Création d'une nouvelle recette

## Technologies

- React 18
- React Router
- useContext + localStorage pour les favoris
- CSS Modules
- ESLint + Prettier

## Installation

```bash
npm install
npm run dev
```

## Scripts

```bash
npm run dev      # Lance le serveur de développement
npm run build    # Build de production
npm run lint     # Vérifie le code avec ESLint
npm run format   # Formate le code avec Prettier
```

## API

[DummyJSON](https://dummyjson.com/docs/recipes) — API publique, aucune clé requise.
